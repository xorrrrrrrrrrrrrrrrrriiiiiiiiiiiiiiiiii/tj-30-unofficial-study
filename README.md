## Writing Markdown

Markdown is the "language" that most files in this repo are written in. Most text editors support it, but it is ideal to use one that has built in GitHub integration such as VS Code (using the Foam plugin) or a native Markdown editor that has GitHub/Git extensions such as Obsidian. Markdown is essentially plaintext with some extra formatting things. A list is below if you would like to use them.

```
Headings - used with 1-6 of the # for different levels
Bold - wrap text with **
Italic - wrap text with *
Blockquote - start text with > and press space
Ordered list:
    1. hello
    2. hi
    3. bye
Unordered list:
    - this is
    - an
    - unordered list
Code - uses three of the `, makes a code block like this one
Link - [title](link)
Image - ![alt text](img.jpg)
```

It is recommended to try and play around with these features in a text editor like Obsidian before trying to make any documents in it.
